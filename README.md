# Triangle Calculator

A phone app (installable web app) for solving triangles on site: brace lengths, stair stringers, roof pitch and any triangle from two or three known values.

- **Right-angled:** rise, run, hypotenuse and angles, plus slope %, ratio 1 : x and rise per metre
- **Any triangle:** any three of sides a, b, c and angles A, B, C, including the case with two possible answers
- Angles in decimal degrees or degrees-minutes-seconds
- Works offline once installed

## Install

Open the app's GitHub Pages address on your phone, then:

- **Android (Chrome):** tap **Install app**, or ⋮ → **Add to Home screen**
- **iPhone (Safari):** Share → **Add to Home Screen**

This folder is generated by `build-app.ps1` from the Triangle Calculator in the Claude Tools repository. Edit the calculator there, not here.
